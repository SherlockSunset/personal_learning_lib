# 知序 · Agent 学习库

面向入门级大模型 Agent 开发工程师的私有学习库。

## 使用

1. 在「API 设置」填写兼容 OpenAI Chat Completions 的 HTTPS Base URL、API Key 和模型 ID。Base URL 一般包含服务商的 `/v1` 路径，也支持完整 `/chat/completions` 地址。
2. 点击「导入知识」，输入公开文章链接、粘贴正文，或上传 TXT、Markdown、HTML。
3. 模型生成简明标题、概括和知识点；编辑内容和分类，选择需要同步的图片，再保存。
4. 使用分类、全文搜索、收藏与待复习视图查找笔记。

固定分类：Python 进阶、Agent 开发、大模型基础、RAG 与检索、工程实践。

笔记和保留图片存储于 Sites R2。网站保持 owner-private；不要直接改为公开网站，公开或多人使用前需要增加记录级授权。
密钥仅存在页面内存，在生成请求中由服务器转发至指定服务商；不会写入笔记、localStorage 或源码。接口地址与模型名记在浏览器便于下次填写。

## 开发

需要 Node.js 22 或更新版本，无第三方依赖。

```sh
npm run build
npm run validate
npm run dev
```

本地预览：http://localhost:5173。预览数据保存在被 Git 忽略的 `.local-data/`，不会发布。
`check.mjs` 检查编译后前端脚本、文章增删改、持久化接口、请求来源、图片接口、网页提取和模拟模型请求。真实模型响应需用户配置服务商后验证。

## v1 边界

- 链接仅支持公开 HTTPS HTML/文本页面。登录可见、反爬限制和依赖 JavaScript 的网页需要粘贴正文。
- 支持 TXT、Markdown、HTML 文件，暂不支持 PDF 或 DOCX。正文最多 60000 字，文件最多 1 MB。
- 每篇最多 12 张 PNG/JPEG/WebP/GIF 图片，每张最多 1.4 MB；图片同步失败会提示，可取消该图片后保存。
- AI 输出需要自行核对；温度参数不兼容的服务商可能需要修改服务端配置。
- 导出备份包含文字笔记与云端图片地址，不包含图片原始文件，暂无备份恢复入口。
- 六篇内置笔记明确标记为示例。个人文章库首次为空时显示示例，添加个人笔记后首页只显示个人笔记。
